# Simple Maze generator.

This is a simple maze-generating script. It uses a stack to create paths, and removes walls in top left and bottom right corners. 
I created some helper classes to ensure clarity on how it works exactly. It has modable sizes.

Will make your child busy for hours :D

## Usage

`poetry run python3 main.py -w [width] -h [height] -count [count]`
width, height are 100 by default (100 cells!)
count is how many files to generate.
